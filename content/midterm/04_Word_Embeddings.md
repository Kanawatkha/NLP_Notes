## 1. Minigame: contexto

- ตัวอย่างเกมทายคำ "คอนเท็กซ์ไทย" (contexto ภาษาไทย) ที่ใช้ความคล้ายของคำเป็นตัวบอกใบ้ ใช้เป็นตัวนำเข้าเรื่อง embedding (ไม่มีเนื้อหาวิชาการเพิ่ม)

## 2. From One-Hot to Dense Vectors

| | One-Hot Encoding | Dense Embedding |
|---|---|---|
| รูปแบบ | คลังคำ $V$ = {แมว, หมา, คน, กิน, ...} | มิติ $d$ = 50–1000 (นิยม 100–300) |
| ตัวอย่าง | แมว = [1, 0, 0, 0, ..., 0], หมา = [0, 1, 0, 0, ..., 0], คน = [0, 0, 1, 0, ..., 0] | แมว = [0.21, −0.44, 0.67, ...], หมา = [0.19, −0.41, 0.71, ...], คน = [−0.55, 0.32, −0.12, ...] |
| ขนาด | $\lvert V \rvert$ (อาจถึง 50,000 มิติ) ใหญ่และเบาบาง (sparse) มาก | สั้นและหนาแน่น (dense) ค่าจริงบวกและลบ |
| ความคล้าย | ทุกคู่ตั้งฉากกันหมด: แมว · หมา = 0 เท่ากับ แมว · คอมพิวเตอร์ = 0 "ความคล้ายของความหมาย" หายไปทั้งหมด | คำที่ความหมายใกล้กันมีเวกเตอร์ใกล้กัน: แมว · หมา สูง, แมว · คอมพิวเตอร์ ต่ำ |
| คำใหม่ (OOV) | แทนไม่ได้เลย | - |
| พารามิเตอร์ | - | น้อยลงมาก → โมเดลปลายทางเรียนได้ดีขึ้นและ overfit น้อยลง |
| คำพ้องความหมาย | - | จับเรื่องคำพ้องความหมายได้ (car / automobile อยู่ใกล้กัน) |

## 3. Word Contexts and Collocations

### The Distributional Hypothesis

> "You shall know a word by the company it keeps." (J. R. Firth, 1957)
> คำที่ปรากฏในบริบทคล้ายกัน มักมีความหมายคล้ายกัน

**ตัวอย่างจากสไลด์ (คำที่ไม่รู้จัก "ตงฉ่าย"):**

```text
"เขาสั่ง ตงฉ่าย มากินกับข้าวต้ม"
"ตงฉ่าย เค็มไปหน่อย ใส่น้อย ๆ นะ"
"ร้านนี้ ตงฉ่าย อร่อยมาก"
```

แม้ไม่เคยรู้จักคำนี้ ก็เดาได้ว่า "ตงฉ่าย" น่าจะเป็นอาหารชนิดหนึ่งที่มีรสเค็ม เพราะบริบทที่มันปรากฏบอกเอง นี่คือหลักการเดียวกับที่คอมพิวเตอร์ใช้

**ความคล้ายระหว่างคำ (Similarity between words)**

| ชนิด | ความหมาย | ตัวอย่าง |
|---|---|---|
| paradigmatic (แทนที่กันได้) | ปรากฏในตำแหน่งคล้ายกัน | ไทย ↔ ญี่ปุ่น |
| syntagmatic (อยู่ด้วยกัน) | ปรากฏร่วมกันในประโยค | ไทย ↔ กรุงเทพ |

ภาพจากตำรา (Fig 5.1): t-SNE ของ word2vec 200 มิติ แสดงว่าคำที่ใกล้ความหมายกับ sweet (candy, chocolate, honey, juice, ...) อยู่ใกล้กันในปริภูมิ

### Collocation: คำที่ "ชอบอยู่ด้วยกัน"

- Collocation = คู่คำที่ปรากฏร่วมกันบ่อยกว่าที่ควรจะเป็นโดยบังเอิญ
- ตัวอย่าง: "น้ำ + ตก", "ตั้ง + ใจ", "ทำ + งาน", "ข้าว + ผัด"
- ความถี่ดิบอย่างเดียวบอกไม่ได้ว่าคู่ไหนน่าสนใจ เพราะคำที่พบบ่อยอย่าง "ที่" หรือ "และ" จะปรากฏร่วมกับทุกคำ
- ต้องการมาตรวัดที่หัก "ความบังเอิญ" ออก นั่นคือ **PMI**

### บริบทของคำ (Word Contexts) 3 แบบ

| แบบ | ความหมาย | ผลที่ได้ |
|---|---|---|
| Document | ทั้งเอกสาร/บทความเป็นบริบทเดียว | ความสัมพันธ์เชิงหัวข้อ (topical) เช่น "หมอ" กับ "โรงพยาบาล" |
| Window $\pm k$ คำ | คำที่อยู่ในหน้าต่าง $k$ คำรอบๆ คำเป้าหมาย | $k$ เล็ก ($\pm 2$) → ความคล้ายเชิง syntax |
| Syntactic | ใช้ความสัมพันธ์ dependency จากสัปดาห์ที่แล้วเป็นบริบท | แม่นยำที่สุดแต่ต้อง parse ก่อน มีค่าใช้จ่ายสูง |

## 1. co-occurrence matrices

### 1) Term-Document Matrix

- แถว = คำ, คอลัมน์ = เอกสาร, ช่อง = จำนวนครั้งที่คำนั้นปรากฏในเอกสารนั้น
- เอกสารสองฉบับคล้ายกัน ถ้าเวกเตอร์คอลัมน์คล้ายกัน (ใช้ใน Information Retrieval)
- ถ่วงน้ำหนักด้วย **TF-IDF** แทนความถี่ดิบ

### 2) Term-Term (Word-Context) Matrix

- แถว = คำเป้าหมาย, คอลัมน์ = คำบริบท, ช่อง = จำนวนครั้งที่ปรากฏร่วมกันในหน้าต่าง
- ขนาด $\lvert V \rvert \times \lvert V \rvert$ เบาบางมาก (ส่วนใหญ่เป็นศูนย์)
- ถ่วงน้ำหนักด้วย **PPMI** แทนความถี่ดิบ (ตัวนี้เป็นตัวที่ใช้ใน Lab)

## 2. Cosine Similarity

**สูตร (5.10)** วัดความคล้ายของเวกเตอร์ $\mathbf{v}$ และ $\mathbf{w}$ ด้วยมุมระหว่างกัน

$$\text{cosine}(\mathbf{v}, \mathbf{w}) = \frac{\mathbf{v} \cdot \mathbf{w}}{\lvert\mathbf{v}\rvert\,\lvert\mathbf{w}\rvert} = \frac{\sum_{i=1}^{N} v_i w_i}{\sqrt{\sum_{i=1}^{N} v_i^2}\,\sqrt{\sum_{i=1}^{N} w_i^2}} \qquad \text{เพราะ}\; \mathbf{a}\cdot\mathbf{b} = \lvert\mathbf{a}\rvert\lvert\mathbf{b}\rvert\cos\theta$$

- ค่าอยู่ระหว่าง 0 ถึง 1 สำหรับเวกเตอร์ความถี่ (ไม่ติดลบ)
- 1 = ทิศทางเดียวกัน, 0 = ตั้งฉาก

### ตัวอย่างจากสไลด์: เมทริกซ์ Term-Term ภาษาไทย (ตัวเลขสมมติเพื่อการสอน)

| | กิน | อาหาร | อ่าน | หนังสือ | รวมแถว |
|---|---|---|---|---|---|
| แมว | 50 | 30 | 1 | 0 | 81 |
| หมา | 45 | 35 | 0 | 1 | 81 |
| คน | 40 | 25 | 35 | 50 | 150 |

**คำนวณ cos(แมว, หมา)**

```text
แมว = [50, 30, 1, 0]
หมา = [45, 35, 0, 1]

dot  = 50(45) + 30(35) + 1(0) + 0(1) = 2250 + 1050 = 3300
|แมว| = sqrt(2500 + 900 + 1 + 0)    = 58.318
|หมา| = sqrt(2025 + 1225 + 0 + 1)   = 57.018

cos = 3300 / (58.318 x 57.018) = 0.9924   <- คล้ายกันมาก
```

**เปรียบเทียบทุกคู่**

| คู่ | cosine |
|---|---|
| cos(แมว, หมา) | 0.9924 |
| cos(แมว, คน) | 0.6191 |
| cos(หมา, คน) | 0.6196 |

ผลตรงกับสัญชาตญาณ: แมวกับหมา (สัตว์ที่กินอาหาร) คล้ายกันมากกว่าที่ทั้งคู่คล้ายกับคน โมเดลเรียนรู้เรื่องนี้จากตัวเลขล้วนๆ โดยไม่มีใครบอกความหมาย

## 3. Pointwise Mutual Information (PMI)

**ปัญหาของความถี่ดิบ:** คำที่พบบ่อยอย่าง "ที่", "และ", "เป็น" ปรากฏร่วมกับทุกคำอยู่แล้ว จึงมีความถี่สูงโดยไม่ได้บอกอะไรเกี่ยวกับความหมาย ต้องการมาตรวัดที่ถามว่า "ปรากฏร่วมกันบ่อยกว่าที่คาดไว้หรือไม่"

- $P(w,c) = f(w,c)/N$ คือสัดส่วนที่ปรากฏร่วมกันจริง
- $P(w)\,P(c)$ คือสัดส่วนที่ควรเป็นถ้าเป็นอิสระต่อกัน

**สูตร**

$$\text{PMI}(\text{word}_1, \text{word}_2) = \log_2 \frac{P(\text{word}_1, \text{word}_2)}{P(\text{word}_1)\,P(\text{word}_2)} \quad (6.14)$$

$$\text{PPMI}(\text{word}_1, \text{word}_2) = \max\left(\log_2 \frac{P(\text{word}_1, \text{word}_2)}{P(\text{word}_1)\,P(\text{word}_2)},\; 0\right) \quad (6.15)$$

| ค่า | ความหมาย |
|---|---|
| PMI > 0 | ปรากฏร่วมกัน "บ่อยกว่า" ที่คาดไว้ → มีความสัมพันธ์กันจริง |
| PMI = 0 | ปรากฏร่วมกันพอดีตามที่คาด → เป็นอิสระต่อกัน |
| PMI < 0 | ปรากฏร่วมกัน "น้อยกว่า" ที่คาด แต่ประมาณค่าได้ไม่น่าเชื่อถือ เพราะต้องใช้คลังข้อมูลมหาศาลจึงจะยืนยันได้ |

**ทางแก้: PPMI (Positive PMI)** = $\max(\text{PMI}(w,c),\, 0)$ ตัดค่าลบทิ้งทั้งหมด เพราะเชื่อถือไม่ได้

## 4. คำนวณ PMI / PPMI จากเมทริกซ์ภาษาไทย

**ขั้นที่ 1: หาผลรวมและความน่าจะเป็น** ($N$ = ผลรวมทั้งเมทริกซ์ = 312)

| | กิน | อาหาร | อ่าน | หนังสือ | รวมแถว |
|---|---|---|---|---|---|
| แมว | 50 | 30 | 1 | 0 | 81 |
| หมา | 45 | 35 | 0 | 1 | 81 |
| คน | 40 | 25 | 35 | 50 | 150 |
| **รวมคอลัมน์** | 135 | 90 | 36 | 51 | **312** |

**ขั้นที่ 2: คำนวณช่อง (แมว, กิน)**

```text
P(แมว, กิน) = 50/312  = 0.1603
P(แมว)      = 81/312  = 0.2596
P(กิน)      = 135/312 = 0.4327

PMI = log2( 0.1603 / (0.2596 x 0.4327) )
    = log2(1.4266) = 0.513
```

**ขั้นที่ 3: ทำซ้ำทุกช่อง แล้วตัดค่าลบทิ้ง (PPMI)**

PMI (ก่อนตัดค่าลบ)

| | กิน | อาหาร | อ่าน | หนังสือ |
|---|---|---|---|---|
| แมว | 0.513 | 0.361 | −3.224 | −∞ |
| หมา | 0.361 | 0.583 | −∞ | −3.727 |
| คน | −0.698 | −0.791 | 1.016 | 1.028 |

PPMI = $\max(\text{PMI}, 0)$ (ใช้เป็นเวกเตอร์ของคำ)

| | กิน | อาหาร | อ่าน | หนังสือ |
|---|---|---|---|---|
| แมว | 0.513 | 0.361 | 0 | 0 |
| หมา | 0.361 | 0.583 | 0 | 0 |
| คน | 0 | 0 | 1.016 | 1.028 |

**ผลของ PPMI:** cos(แมว, หมา) = **0.92** แต่ cos(แมว, คน) = **0.00** PPMI แยกกลุ่มความหมายได้ชัดเจนกว่าความถี่ดิบมาก (ความถี่ดิบให้ 0.9924 และ 0.6191)

**จาก Lab 4:** ฟังก์ชัน PPMI ใช้ $P_\alpha(c) = \dfrac{\text{count}(c)^\alpha}{\sum_c \text{count}(c)^\alpha}$ กับ $\alpha = 0.75$ (smoothing) และผลที่ Lab แสดงคือคู่ที่ปรากฏบ่อยมาก เช่น at–rice มีความถี่ดิบมากกว่า eats–rice แต่ PPMI ต่ำกว่า เพราะ "at" ปรากฏกับทุกคำอยู่แล้ว

## 5. Weighted PMI

**ปัญหา:** PMI เอนเอียงกับเหตุการณ์ที่เกิดน้อย (infrequent event)

**ตัวอย่างจากสไลด์** (เพิ่มคอลัมน์ "เหมียว" ที่พบน้อย รวมทั้งเมทริกซ์ $N = 262$)

| | กิน | อาหาร | อ่าน | เหมียว | รวมแถว |
|---|---|---|---|---|---|
| แมว | 50 | 30 | 1 | 1 | 82 |
| หมา | 45 | 35 | 0 | 0 | 80 |
| คน | 40 | 25 | 35 | 0 | 100 |
| **รวมคอลัมน์** | 135 | 90 | 36 | 1 | **262** |

$$\text{PMI}(w,c) = \log_2 \frac{N \cdot f(w,c)}{f(w)\cdot f(c)}$$

| คู่ | การคำนวณ | PMI |
|---|---|---|
| แมว–กิน | $\log_2 \dfrac{262 \times 50}{82 \times 135} = \log_2 \dfrac{13100}{11070} = \log_2 1.1834$ | ≈ 0.243 |
| แมว–อาหาร | $\log_2 \dfrac{262 \times 30}{82 \times 90} = \log_2 \dfrac{7860}{7380} = \log_2 1.0650$ | ≈ 0.091 |
| แมว–อ่าน | $\log_2 \dfrac{262 \times 1}{82 \times 36} = \log_2 \dfrac{262}{2952} = \log_2 0.0888$ | ≈ −3.494 |
| แมว–เหมียว | $\log_2 \dfrac{262 \times 1}{82 \times 1} = \log_2 3.1951$ | ≈ 1.676 |

คู่ แมว–เหมียว ได้ PMI สูงสุดทั้งที่ปรากฏเพียง 1 ครั้ง เป็นตัวอย่างความเอนเอียงต่อเหตุการณ์ที่เกิดน้อย

> หมายเหตุ: สไลด์เขียนค่าแมว–กิน เป็น ≈ 0.244 ผมคำนวณซ้ำได้ 0.243

**วิธีแก้ (Weighting PMI)**

1. **K-smoothing:** เพิ่มค่า smoothing $k = 2$ ในทุกช่อง
2. **Context distribution smoothing:** กำหนดความน่าจะเป็นของคำที่พบน้อยให้สูงขึ้น

$$P_\alpha(c) = \frac{\text{count}(c)^\alpha}{\sum_c \text{count}(c)^\alpha}$$

## 6. TF-IDF (Term Frequency x Inverse Document Frequency)

- คือวิธีให้น้ำหนักคำใน term-document matrix
  - ให้คะแนนสูงกับคำที่ **เจอบ่อยในเอกสารนี้ แต่เจอน้อยในเอกสารอื่น**
  - ให้คะแนนต่ำกับคำที่เจอทุกที่ (เช่น "ที่", "และ", "การ")
- TF-IDF ใช้กับเมทริกซ์แบบ term-document ส่วน PPMI ใช้กับแบบ term-term
- มีวิธีถ่วงน้ำหนักสองแบบคือ tf-idf และตัวแปรของมันชื่อ BM25

**สูตร**

$$\text{tf}_{t,d} = \begin{cases} 1 + \log_{10} \text{count}(t,d) & \text{ถ้า } \text{count}(t,d) > 0 \\ 0 & \text{otherwise} \end{cases} \quad (11.4)$$

$$\text{idf}_t = \log_{10} \frac{N}{\text{df}_t} \quad (11.5) \qquad\qquad \text{tf-idf}(t,d) = \text{tf}_{t,d} \cdot \text{idf}_t \quad (11.6)$$

| สัญลักษณ์ | ความหมาย |
|---|---|
| tf | เจอคำ $t$ ในเอกสาร $d$ บ่อยแค่ไหน |
| $N$ | จำนวนเอกสารทั้งหมด |
| df | จำนวนเอกสารที่มีคำ $t$ อย่างน้อยหนึ่งครั้ง |

**ตัวอย่างจากสไลด์ ($N = 3$ เอกสาร)**

| word | d1 | d2 | d3 | df | idf = $\log_{10}(3/\text{df})$ |
|---|---|---|---|---|---|
| เป็ด | 3 | 2 | 0 | 2 | 0.176 |
| ที่ | 10 | 8 | 9 | 3 | **0** |
| รถ | 0 | 0 | 5 | 1 | 0.477 |

| คำในเอกสาร | tf (ตามสไลด์) | $\times$ idf | TF-IDF |
|---|---|---|---|
| tf-idf(เป็ด, d1) | $\log_{10} 4 = 0.602$ | $\times\, 0.176$ | **0.106** |
| tf-idf(ที่, d1) | $\log_{10} 11 = 1.041$ | $\times\, 0$ | **0** |
| tf-idf(รถ, d3) | $\log_{10} 6 = 0.778$ | $\times\, 0.477$ | **0.371** |

ข้อสังเกต: "ที่" ปรากฏทุกเอกสาร จึงได้ idf = 0 และ TF-IDF = 0 ไม่ว่าจะพบกี่ครั้ง

> หมายเหตุสำคัญ: ตัวอย่างข้างบนในสไลด์ใช้ $\text{tf} = \log_{10}(\text{count} + 1)$ (เช่น เป็ด count 3 ใช้ $\log_{10} 4$) ซึ่ง **ไม่ตรงกับสูตร (11.4)** บนสไลด์เดียวกัน ถ้าใช้สูตร (11.4) ตรงๆ จะได้: tf-idf(เป็ด, d1) = $(1 + \log_{10} 3) \times 0.176 = 0.260$, tf-idf(ที่, d1) = 0, tf-idf(รถ, d3) = $(1 + \log_{10} 5) \times 0.477 = 0.811$ ใน Lab 4 ใช้สูตร (11.4) และ (11.5) ตามตำรา ควรถามอาจารย์ว่าข้อสอบใช้สูตรไหน

**จาก Lab 4:** scikit-learn `TfidfVectorizer` ใช้สูตรต่างออกไป: $\text{idf}_t = \ln\dfrac{1+N}{1+\text{df}_t} + 1$ แล้วทำ L2 normalization ของแต่ละเอกสาร ทำให้คำที่อยู่ในทุกเอกสารยังมีน้ำหนักเล็กน้อยที่ไม่เป็นศูนย์ ก่อนเทียบตัวเลขข้ามเครื่องมือต้องตรวจก่อนว่าไลบรารีใช้สูตรไหน

## 7. Explicit vs. Implicit Representations

| ประเด็น | Explicit / Sparse (นับ) | Implicit / Dense (ทำนาย) |
|---|---|---|
| ตัวอย่างวิธี | Co-occurrence counts, tf-idf, PPMI, LSA | Word2Vec, GloVe, FastText |
| จำนวนมิติ | $\lvert V \rvert$ หลักหมื่นถึงแสน | $d$ = 50–1000 (นิยม 100–300) |
| ตีความมิติได้ไหม | ได้ แต่ละมิติคือบริบทหนึ่งคำ | ไม่ได้ มิติไม่มีความหมายชัดเจน |
| ค่าในเวกเตอร์ | ไม่ติดลบ (ความถี่หรือ PPMI) | เป็นได้ทั้งบวกและลบ |
| วิธีได้มา | นับตรงๆ จากคลังข้อมูล | ฝึกโมเดลให้ทำนายบริบท |
| ประสิทธิภาพงานปลายทาง | ใช้ได้ แต่ด้อยกว่า | ดีกว่าในแทบทุกงาน NLP |

# ส่วนที่ 3: word2vec และ Static embedding

## 1. Prediction based model

แทนที่จะ "นับ" ว่าคำบริบทปรากฏใกล้คำเป้าหมายกี่ครั้ง ให้ train classifier ทำนายว่า "คำนี้น่าจะปรากฏใกล้กันไหม" แล้วเอา **น้ำหนักที่เรียนรู้ได้** มาใช้เป็น embedding (ไม่สนใจผลการทำนายเลย)

### Self-Supervision

- ไม่ต้องมีมนุษย์มากำกับข้อมูล ข้อความปกติที่มีอยู่แล้วคือข้อมูลฝึก
- คำที่ปรากฏใกล้ "แมว" จริงๆ ในข้อความ = คำตอบที่ถูก (**positive example**)
- สุ่มคำอื่นจากคลังคำมาเป็นคำตอบที่ผิด (**negative example**)
- ฝึก logistic regression แยกสองกรณีนี้ → น้ำหนักที่ได้คือ embedding

### word2vec Architecture

| แบบ | ทำอะไร | ดีกับ |
|---|---|---|
| Skip-gram | ใช้คำกลางทำนายบริบทรอบๆ | คำที่พบน้อยและคลังเล็ก |
| CBOW (Continuous Bag-of-Words) | ใช้บริบทรอบๆ ทำนายคำกลาง | เร็วกว่า ดีกับคำที่พบบ่อย |

## 2. Skip-gram Architecture: ใช้คำกลางทำนายบริบท

- เก็บ embedding **สองชุดต่อคำ**: target embedding (input) ชุด $W$ และ context embedding (output) ชุด $C$
- พารามิเตอร์ $\theta$ เป็นเมทริกซ์ $2\lvert V \rvert$ เวกเตอร์ ขนาด $d$ ที่ต่อ $W$ กับ $C$ เข้าด้วยกัน (Fig 5.6)

**ความน่าจะเป็นของคู่ (w, c):**

$$P(+ \mid w, c) = \sigma(c \cdot w) \qquad \sigma(x) = \frac{1}{1 + e^{-x}}$$

$w$ = target word, $c$ = context และ noise word ยิ่ง dot product สูง ยิ่งน่าจะอยู่ใกล้กัน

### ตัวอย่างการสร้างข้อมูลฝึกจากสไลด์

ประโยค: `... lemon, a [tablespoon of apricot jam, a] pinch ...` ตำแหน่ง $c_1$ ถึง $c_4$ ขนาดหน้าต่าง $L = \pm 2$ ตัว target word $w$ = **apricot** มีคำบริบท 4 คำ ได้ **positive 4 คู่**

| positive (+) | | negative (−) ($k = 2$ ต่อ positive 1 คู่ = 8 คู่) | |
|---|---|---|---|
| $w$ | $c_{pos}$ | $w$ | $c_{neg}$ |
| apricot | tablespoon | apricot | aardvark, my |
| apricot | of | apricot | where, coaxial |
| apricot | jam | apricot | seven, forever |
| apricot | a | apricot | dear, if |

## 3. Training Word2Vec (Skip-gram with Negative Sampling)

**Binary classification:** เป้าหมาย "คู่นี้เป็นคู่จริง (+) หรือคู่ปลอม (−)"

**Loss function**

$$L(w, c_{pos}, c_{neg_{1..k}}) = -\log\left[ P(+\mid w, c_{pos}) \prod_{i=1}^{k} P(-\mid w, c_{neg_i}) \right]$$

$$= -\left[ \log\sigma(c_{pos} \cdot w) + \sum_{i=1}^{k} \log\sigma(-c_{neg_i} \cdot w) \right] \qquad (5.21)$$

**ทิศทางการปรับ (Fig 5.7):** เลื่อน $w$ (apricot) ให้ใกล้ $c_{pos}$ (jam) มากขึ้น (dot product สูงขึ้น) และไกลจาก $c_{neg}$ (matrix, Tolstoy) (dot product ต่ำลง)

**สูตรอัปเดตด้วย gradient descent** ($\eta$ = learning rate, $t$ = รอบก่อนหน้า)

$$c_{pos}^{t+1} = c_{pos}^t - \eta\,[\sigma(c_{pos}^t \cdot w^t) - 1]\,w^t \qquad (5.25)$$

$$c_{neg_i}^{t+1} = c_{neg_i}^t - \eta\,[\sigma(c_{neg_i}^t \cdot w^t)]\,w^t \qquad (5.26)$$

$$w^{t+1} = w^t - \eta\left[ [\sigma(c_{pos}^t \cdot w^t) - 1]\,c_{pos}^t + \sum_{i=1}^{k} [\sigma(c_{neg_i}^t \cdot w^t)]\,c_{neg_i}^t \right] \qquad (5.27)$$

**ผลลัพธ์ที่ได้:** dense vector จับความสัมพันธ์เชิงความหมายได้ เช่น $v(\text{king}) - v(\text{man}) + v(\text{woman}) \approx v(\text{queen})$

**จาก Lab 4** การฝึก skip-gram ด้วย gensim `Word2Vec` มีอาร์กิวเมนต์สอดคล้องกับทฤษฎีดังนี้

| ทฤษฎี | gensim |
|---|---|
| skip-gram | `sg=1` (CBOW คือ `sg=0`) |
| negative sampling $k$ ตัว (ไม่ใช้ hierarchical softmax) | `negative=k`, `hs=0` |
| noise distribution $P_\alpha$ ที่ $\alpha = 0.75$ | `ns_exponent=0.75` |
| context window $\pm L$ | `window=L` |
| ขนาด embedding $d$ | `vector_size=d` |
| ตัดคำที่พบน้อย | `min_count` |
| learning rate ลดเชิงเส้น | `alpha` (เริ่ม) → `min_alpha` (จบ) |
| จำนวนรอบ | `epochs` |

## 4. Word2Vec Hyperparameters

| พารามิเตอร์ | ค่าที่นิยม | ผลกระทบ |
|---|---|---|
| dimension $d$ | 100–300 | ใหญ่ขึ้น = จับความหมายละเอียดขึ้น แต่ต้องใช้ข้อมูลมากขึ้นและเสี่ยง overfit |
| window size | $\pm 2$ ถึง $\pm 10$ | หน้าต่างเล็ก → ความคล้ายเชิงวากยสัมพันธ์, หน้าต่างใหญ่ → ความคล้ายเชิงหัวข้อ |
| negative samples $k$ | 5–20 | คลังเล็กใช้ $k$ มาก (15–20), คลังใหญ่ใช้ $k$ น้อย (2–5) ก็พอ |
| min count | 5 | ตัดคำที่พบน้อยกว่านี้ทิ้ง ลดสัญญาณรบกวนและขนาดโมเดล |
| subsampling $t$ | 1e-3 ถึง 1e-5 | สุ่มทิ้งคำที่พบบ่อยมาก (เช่น "ที่", "และ") เพื่อให้โมเดลโฟกัสคำที่มีสาระ |
| epochs | 5–15 | มากขึ้นช่วยกับคลังเล็ก แต่คลังใหญ่ผ่านรอบเดียวก็มักพอ |
| learning rate $\eta$ | 0.025 (ลดลงเรื่อยๆ) | สูงเกินไปสู่ออก, ต่ำเกินไปเรียนช้า |

**ข้อควรระวังสำหรับภาษาไทย:** ต้องตัดคำให้ถูกต้องก่อนเสมอ (สัปดาห์ที่ 2) ถ้าตัดคำผิด embedding ทั้งหมดจะผิดตามไปด้วย

## 5. Other kinds of static embedding: FastText

| ปัญหาของ Word2Vec | ทางแก้: FastText (Bojanowski et al., 2017) |
|---|---|
| คำที่ไม่เคยเห็นตอนฝึก (OOV) ไม่มีเวกเตอร์เลย | แทนคำด้วยผลรวมของ **character n-grams** ของตัวมันเอง |
| คำที่พบน้อยได้เวกเตอร์คุณภาพต่ำ | คำที่ไม่เคยเห็นก็ยังประกอบเวกเตอร์ขึ้นมาได้จากชิ้นส่วนย่อย |
| ภาษาที่มีการผันคำมาก แต่ละรูปเป็นคนละคำหมด ทั้งที่รากศัพท์เดียวกัน | ใช้สถาปัตยกรรม skip-gram เดิมทุกอย่าง เปลี่ยนแค่วิธีแทนคำ |

**ตัวอย่างจากสไลด์: แตกคำเป็น character n-grams ($n = 3$)**

```text
อังกฤษ:  "where"  →  <wh , whe , her , ere , re>  +  <where>

ไทย:     "ความสุข" →  <คว , ควา , วาม , ามส , มสุ , สุข , ุข>  +  <ความสุข>
         คำใหม่ "ความสงบ" ที่ไม่เคยเห็น ยังใช้ n-gram "<คว", "ควา", "วาม" ร่วมกับคำที่เคยเห็นได้
```

เหมาะกับภาษาไทยเป็นพิเศษ: ภาษาไทยสร้างคำใหม่ด้วยการประสมคำอยู่ตลอด (ความ+สุข, นัก+เรียน, การ+ทำงาน) FastText จับโครงสร้างนี้ได้โดยไม่ต้องเห็นคำประสมนั้นมาก่อน

## 6. Other kinds of static embedding: GloVe

**Global Vectors for Word Representation (GloVe)**

- Word2Vec ดูทีละ window เท่านั้น
- GloVe ใช้สถิติ **global co-occurrence**
- เป็น log-bilinear model
- ใช้ "อัตราส่วน" ของความน่าจะเป็นการปรากฏร่วม ไม่ใช่ตัวความน่าจะเป็นเอง

**ตัวอย่างจากสไลด์ (ice และ steam)**

| | $k$ = solid | $k$ = gas | $k$ = water | $k$ = fashion |
|---|---|---|---|---|
| $P(k \mid \text{ice})$ | $1.9 \times 10^{-4}$ | $6.6 \times 10^{-5}$ | $3.0 \times 10^{-3}$ | $1.7 \times 10^{-5}$ |
| $P(k \mid \text{steam})$ | $2.2 \times 10^{-5}$ | $7.8 \times 10^{-4}$ | $2.2 \times 10^{-3}$ | $1.8 \times 10^{-5}$ |
| $P(k \mid \text{ice}) / P(k \mid \text{steam})$ | 8.9 | $8.5 \times 10^{-2}$ | 1.36 | 0.96 |

อัตราส่วนสูง (solid) = เกี่ยวกับ ice, ต่ำ (gas) = เกี่ยวกับ steam, ใกล้ 1 (water, fashion) = เกี่ยวกับทั้งสองหรือไม่เกี่ยวกับทั้งคู่

# ส่วนที่ 4: Contextual embedding

## 1. Problem of static (Polysemy)

Static embedding ให้ 1 เวกเตอร์ต่อ 1 คำ ไม่ว่าจะมีกี่ความหมาย

| ประโยค | ความหมายของ "ขัน" |
|---|---|
| ไก่ขันตอนตีห้า | ร้อง (เสียงไก่) |
| เรื่องนี้น่าขันจริงๆ | ตลก |
| ตักน้ำด้วยขันใบเล็ก | ภาชนะ |

ทั้งสามประโยคได้เวกเตอร์เดียวกัน E["ขัน"] ทุกความหมายปนอยู่ในเวกเตอร์เดียว

## 2. Contextual embedding: Type vs instance

- **Static embeddings** แทนความหมายของ **word types** (รายการในคลังศัพท์)
- **Contextual embeddings** แทนความหมายของ **word instances** คือคำชนิดหนึ่งในบริบทหนึ่งๆ

ภาพจากตำรา (Fig 9.7): งาน all-words WSD โดยแต่ละคำในประโยค (electric, guitar, bass, player, stand, side) ถูกแม็ปไปยังความหมายที่ถูกต้องใน WordNet (เช่น bass → bass$^7$ = instrument)

## 3. Static vs Contextual: comparison

| | Static (word2vec, GloVe, fastText) | Contextual (ELMo, BERT) |
|---|---|---|
| vector | word type: 1 เวกเตอร์ต่อคำในคลังศัพท์ | word instance: 1 เวกเตอร์ต่อคำในแต่ละประโยค |
| คำกำกวม | ทุกความหมายปนในเวกเตอร์เดียว | แยกตามบริบทได้ |
| ขนาดทั่วไป | 50–300 มิติ | 768 (BERT-base), 1024 (ELMo, BERT-large) |
| เป้าหมายตอนเทรน | ทำนายคำรอบข้าง / factorize co-occurrence | language model: ทำนายคำถัดไป (ELMo) หรือคำที่ถูกปิด (BERT) |
| นำไปใช้ | เป็น feature ป้อนโมเดลอื่น | เป็น feature หรือ fine-tune ทั้งโมเดล |
| ต้นทุน | ถูกมาก | ต้องรัน network ลึกทุกครั้ง |

# ส่วนที่ 5: Evaluation และประเด็นอื่นๆ

## 1. Evaluating Word Embeddings

| ชนิด | อธิบาย |
|---|---|
| **Extrinsic** (สำคัญที่สุด) | นำ embedding ไปใช้ในงานจริง (เช่น การจำแนกข้อความ, NER, การแปล) แล้วดูว่าผลดีขึ้นหรือไม่เทียบกับวิธีอื่น แต่แพง |
| **Intrinsic** (สะดวก เร็ว) | วัดคุณภาพเวกเตอร์โดยตรง |

**Intrinsic evaluation มี 3 แบบ**

- **Word Similarity:** เทียบ cosine ของโมเดลกับคะแนนที่มนุษย์ให้
- **Word Analogy:** a:b :: a*:? ด้วยวิธี parallelogram
- **Categorization / Clustering:** จัดกลุ่มคำได้ตรงหมวดหรือไม่

**ตัวอย่างจากสไลด์ (Intrinsic Evaluation ภาษาไทย)**

| คู่คำ | คะแนนมนุษย์ (0–10) | อันดับ | cosine ของโมเดล | อันดับ |
|---|---|---|---|---|
| แมว – หมา | 9.0 | 1 | 0.92 | 1 |
| กิน – ทาน | 8.5 | 2 | 0.65 | 3 |
| รถ – รถยนต์ | 7.0 | 3 | 0.81 | 2 |
| แมว – หนังสือ | 3.0 | 4 | 0.30 | 4 |
| ปลา – คอมพิวเตอร์ | 1.5 | 5 | 0.12 | 5 |

อันดับของโมเดลตรงกับมนุษย์ 3 จาก 5 คู่ (ต่างกันที่ กิน–ทาน และ รถ–รถยนต์)

## 2. Word Analogy และ Visualizing Embeddings

### Word Analogy: วิธี Parallelogram

โจทย์ $a : b :: a^* : b^*$ ให้เวกเตอร์ $a$, $b$, $a^*$ และต้องหา $b^*$

$$\hat{b}^* = \arg\min_{x}\; \text{distance}(x,\; b - a + a^*) \qquad (5.28)$$

ตัวอย่าง: $\text{king} - \text{man} + \text{woman} \approx \text{queen}$ และ $\text{กรุงเทพ} - \text{ไทย} + \text{ญี่ปุ่น} \approx \text{โตเกียว}$

ภาพจากตำรา (Fig 5.8): ตำแหน่งของ *vine* หาได้จากการลบ *apple* จาก *tree* แล้วบวก *grape*

### Visualizing Embeddings

embedding มี 100–300 มิติ ต้องลดเหลือ 2–3 มิติจึงจะวาดได้

| วิธี | ลักษณะ |
|---|---|
| PCA | เชิงเส้น เร็ว รักษาโครงสร้างภาพรวม เหมาะดูทิศทางหลัก |
| t-SNE | ไม่เชิงเส้น เน้นรักษา "เพื่อนบ้านใกล้" ทำให้เห็นกลุ่มคำชัดเจน |
| UMAP | เร็วกว่า t-SNE และรักษาโครงสร้างภาพรวมได้ดีกว่า |

## 3. Embedding Bias

**ตัวอย่างที่มีชื่อเสียง (Bolukbasi et al., 2016):** "computer programmer" − "man" + "woman" → ผลลัพธ์ที่ใกล้ที่สุดคือ "homemaker" และโมเดลยังให้ analogy ว่า "father : doctor :: mother : nurse" อคติเหล่านี้เรียนรู้มาจากข้อความข่าวที่ใช้ฝึกโดยตรง

| ชนิด | อธิบาย |
|---|---|
| Allocational Harm | ระบบจัดสรรทรัพยากร (งาน สินเชื่อ) อย่างไม่เป็นธรรม เช่น ระบบคัดกรองใบสมัครงานลดคะแนนเอกสารที่มีชื่อผู้หญิงโดยไม่ตั้งใจ |
| Representational Harm | ระบบลดทอนคุณค่าหรือมองข้ามคนบางกลุ่ม เช่น ชื่อของคนบางเชื้อชาติมี cosine สูงกับคำเชิงลบ (Caliskan et al., 2017) |
| Bias Amplification | embedding ไม่เพียงสะท้อนอคติในข้อมูล แต่ยัง "ขยาย" ให้เด่นชัดกว่าสถิติจริงในข้อมูลต้นทางเสียอีก |

**สถานะปัจจุบันของการแก้ปัญหา:** มีงานวิจัยพยายาม "debias" ด้วยการแปลงปริภูมิให้ลบทิศทางที่เป็นแบบเหมารวมออก แต่ Gonen & Goldberg (2019) แสดงว่าวิธีเหล่านี้ลดอคติได้แต่ไม่ได้กำจัดจริง อคติเพียงถูกซ่อนลึกลง ยังคงเป็นปัญหาเปิดที่ยังไม่มีคำตอบ

# ส่วนที่ 6: Semantic drift

## 1. Semantic drift

**นิยาม:** Semantic drift / semantic change คือปรากฏการณ์ที่ความหมายของคำเปลี่ยนไปตามกาลเวลา ตัวคำสะกดเหมือนเดิม แต่บริบทที่คนใช้เปลี่ยนไป

| ประเภท | ความหมาย | ตัวอย่าง |
|---|---|---|
| Broadening | ความหมายกว้างขึ้น | "เมาส์" เดิมหมายถึงหนู → รวมอุปกรณ์คอมพิวเตอร์ |
| Narrowing | ความหมายแคบลง | อังกฤษ "meat" เดิมแปลว่าอาหารทุกชนิด → เหลือเฉพาะเนื้อสัตว์ |
| Pejoration | ความหมายแย่ลง | อังกฤษ "awful" จาก "เต็มไปด้วยความน่าเกรงขาม" → "แย่มาก" |
| Amelioration | ความหมายดีขึ้น | ไทย "ปัง" จากเสียงดัง/ขนมปัง → "ยอดเยี่ยม" |
| Metaphorical | ขยายเชิงอุปมา | ไทย "เท" จากเทน้ำ → "ทิ้งนัด/ทิ้งแฟน" |

**ผลกระทบ:** โมเดลที่ฝึกด้วยข้อมูลเก่าจะเข้าใจภาษาปัจจุบันผิด งานวิเคราะห์ความรู้สึกอาจตีความ "ปัง" หรือ "เท" ผิดขั้ว และการวัด drift ยังเป็นเครื่องมือศึกษาสังคมและวัฒนธรรมได้ด้วย

## 2. Example (Case Study)

ภาษาอังกฤษ (Hamilton et al., 2016)

| คำ | ราวปี 1850–1900 | ราวปี 2000 |
|---|---|---|
| gay | 1900: ร่าเริง / สนุกสนาน | เกี่ยวกับรักร่วมเพศ |
| broadcast | 1900: หว่านเมล็ดพืช | กระจายเสียง/แพร่ภาพ |
| awful | 1850: เต็มไปด้วยความน่าเกรงขาม | แย่มาก น่ากลัว |

ภาพจากตำรา (Fig 5.10): t-SNE แสดงการเคลื่อนที่ของเวกเตอร์ gay, broadcast, awful ข้ามทศวรรษด้วย word2vec

## 3. Method

| ขั้น | ชื่อ | ทำอะไร |
|---|---|---|
| 1 | แบ่งคลังข้อมูลตามช่วงเวลา | แบ่งข้อความเป็นช่วง (decade, ปี, หรือ 2 ช่วงเวลา เช่น 2010 และ 2026) |
| 2 | ฝึก embedding แยกแต่ละช่วง | ฝึก word2vec/GloVe แยกกันบนข้อมูลของแต่ละช่วง ได้ปริภูมิเวกเตอร์คนละชุด |
| 3 | จัดปริภูมิให้ตรงกัน (Alignment) | ปริภูมิที่ฝึกแยกกันจะมีการหมุน/สะท้อนต่างกัน ต้องแปลงให้เทียบกันได้ก่อน |
| 4 | วัดระยะการเปลี่ยนแปลง | คำนวณ cosine ระหว่างเวกเตอร์ของคำเดียวกันข้ามช่วงเวลา ยิ่งต่ำ ยิ่งเปลี่ยนมาก |
| 5 | ตรวจสอบเชิงคุณภาพ | ดูคำเพื่อนบ้านที่ใกล้ที่สุดในแต่ละช่วงเวลา เพื่อยืนยันว่าการเปลี่ยนแปลงมีความหมายจริง |

## 4. Statistical Laws of Semantic Change

Hamilton, Leskovec & Jurafsky (2016) วิเคราะห์ embedding ข้ามศตวรรษในหลายภาษา แล้วพบกฎเชิงสถิติสองข้อที่เป็นจริงข้ามภาษา

| กฎ | เนื้อหา |
|---|---|
| Law of Conformity (กฎแห่งความสอดคล้อง) | อัตราการเปลี่ยนความหมายแปรผกผันกับความถี่ของคำ: คำที่ใช้บ่อยมาก (เช่น "กิน", "ไป", "น้ำ") เปลี่ยนความหมายช้ากว่าคำที่ใช้น้อย |
| Law of Innovation (กฎแห่งนวัตกรรม) | เมื่อควบคุมความถี่แล้ว คำที่มีหลายความหมาย (polysemous) เปลี่ยนความหมายเร็วกว่า: คำที่ความหมายกำกวมอยู่แล้วเปิดช่องให้ความหมายใหม่แทรกเข้ามาได้ง่าย |

**การนำไปใช้:** คำที่พบน้อยจะมี drift สูงโดยธรรมชาติเพราะเวกเตอร์ประมาณค่าได้ไม่แม่น ไม่ใช่เพราะความหมายเปลี่ยนจริง วิธีปฏิบัติ: เทียบเฉพาะคำที่มีความถี่ใกล้เคียงกัน หรือใช้คำควบคุมที่ความถี่พอๆ กันเป็นฐานเปรียบเทียบ

### ข้อ 1  กำหนดเมทริกซ์ Term-Term ต่อไปนี้ จงหา cosine similarity ของ (แมว, หมา) และ (แมว, คน) จากความถี่ดิบ แล้วบอกว่าคู่ใดคล้ายกันมากกว่า

| | กิน | อาหาร | อ่าน | หนังสือ | รวมแถว |
|:---:|:---:|:---:|:---:|:---:|:---:|
| แมว | 50 | 30 | 1 | 0 | 81 |
| หมา | 45 | 35 | 0 | 1 | 81 |
| คน | 40 | 25 | 35 | 50 | 150 |
| รวมคอลัมน์ | 135 | 90 | 36 | 51 | 312 |

$\mathbf{Sol}^{n}$

ใช้ $\cos(\mathbf{a},\mathbf{b})=\dfrac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}|\,|\mathbf{b}|}$ โดยหา dot product และขนาดของแต่ละเวกเตอร์ก่อน

$$
\begin{aligned}
|\text{แมว}| &= \sqrt{50^2+30^2+1^2+0^2} = \sqrt{3401} = 58.318 \\
|\text{หมา}| &= \sqrt{45^2+35^2+0^2+1^2} = \sqrt{3251} = 57.018 \\
|\text{คน}| &= \sqrt{40^2+25^2+35^2+50^2} = \sqrt{5950} = 77.136 \\
\text{แมว}\cdot\text{หมา} &= 50(45)+30(35)+1(0)+0(1) = 3300 \\
\text{แมว}\cdot\text{คน} &= 50(40)+30(25)+1(35)+0(50) = 2785 \\
\cos(\text{แมว},\text{หมา}) &= \frac{3300}{58.318\times57.018} = 0.9924 \\
\cos(\text{แมว},\text{คน}) &= \frac{2785}{58.318\times77.136} = 0.6191
\end{aligned}
$$

$\mathbf{Ans}\quad \cos(\text{แมว},\text{หมา})=\mathbf{0.9924}$ และ $\cos(\text{แมว},\text{คน})=\mathbf{0.6191}$ ดังนั้นแมวกับหมาคล้ายกันมากกว่า

### ข้อ 2  จากเมทริกซ์ในข้อ 1 ($N=312$) จงหา PMI ของทุกช่อง แล้วตัดค่าลบเป็น PPMI

$\mathbf{Sol}^{n}$

ใช้ $\text{PMI}(w,c)=\log_2\dfrac{P(w,c)}{P(w)P(c)}=\log_2\dfrac{N\cdot f(w,c)}{f(w)\,f(c)}$ และ $\text{PPMI}=\max(\text{PMI},0)$ ถ้า $f(w,c)=0$ ถือว่า PMI เป็น $-\infty$ และ PPMI เป็น $0$

ตัวอย่างการคำนวณ

$$
\begin{aligned}
\text{PMI}(\text{แมว},\text{กิน}) &= \log_2\frac{0.1603}{0.2596\times0.4327} = \log_2 1.4266 = 0.513 &&P=\tfrac{50}{312},\ \tfrac{81}{312},\ \tfrac{135}{312} \\
\text{PMI}(\text{คน},\text{หนังสือ}) &= \log_2\frac{312\times50}{150\times51} = \log_2 2.0392 = 1.028
\end{aligned}
$$

ทำซ้ำทุกช่องด้วยสูตรเดียวกัน

| PMI | กิน | อาหาร | อ่าน | หนังสือ |
|:---:|:---:|:---:|:---:|:---:|
| แมว | 0.513 | 0.361 | $-3.224$ | $-\infty$ |
| หมา | 0.361 | 0.583 | $-\infty$ | $-3.727$ |
| คน | $-0.698$ | $-0.791$ | 1.016 | 1.028 |

ตัดค่าลบเป็น $0$

$\mathbf{Ans}$

| PPMI | กิน | อาหาร | อ่าน | หนังสือ |
|:---:|:---:|:---:|:---:|:---:|
| แมว | 0.513 | 0.361 | 0 | 0 |
| หมา | 0.361 | 0.583 | 0 | 0 |
| คน | 0 | 0 | 1.016 | 1.028 |

### ข้อ 3  จากเวกเตอร์ PPMI ในข้อ 2 จงหา $\cos(\text{แมว},\text{หมา})$ และ $\cos(\text{แมว},\text{คน})$ แล้วเปรียบเทียบกับข้อ 1

$\mathbf{Sol}^{n}$

เวกเตอร์ PPMI คือ แมว $=[0.513,\,0.361,\,0,\,0]$, หมา $=[0.361,\,0.583,\,0,\,0]$ และ คน $=[0,\,0,\,1.016,\,1.028]$

$$
\begin{aligned}
\text{แมว}\cdot\text{หมา} &= 0.513(0.361)+0.361(0.583) = 0.1852+0.2105 = 0.3957 \\
|\text{แมว}| &= \sqrt{0.513^2+0.361^2} = 0.6273 \\
|\text{หมา}| &= \sqrt{0.361^2+0.583^2} = 0.6857 \\
\cos(\text{แมว},\text{หมา}) &= \frac{0.3957}{0.6273\times0.6857} = 0.92 \\
\text{แมว}\cdot\text{คน} &= 0 &&\text{ไม่มีมิติที่ไม่เป็นศูนย์ร่วมกัน} \\
\cos(\text{แมว},\text{คน}) &= 0
\end{aligned}
$$

| คู่ | cosine จากความถี่ดิบ (ข้อ 1) | cosine จาก PPMI |
|:---:|:---:|:---:|
| (แมว, หมา) | 0.9924 | 0.92 |
| (แมว, คน) | 0.6191 | 0.00 |

$\mathbf{Ans}\quad \cos(\text{แมว},\text{หมา})=\mathbf{0.92}$ และ $\cos(\text{แมว},\text{คน})=\mathbf{0}$ PPMI แยกกลุ่มความหมายได้ชัดเจนกว่าความถี่ดิบมาก

### ข้อ 4  กำหนดเอกสาร 3 ฉบับ ($N=3$) ดังตาราง จงหา $\text{tf-idf}(\text{เป็ด},d_1)$, $\text{tf-idf}(\text{ที่},d_1)$ และ $\text{tf-idf}(\text{รถ},d_3)$ ด้วยสูตร $\text{tf}=1+\log_{10}\text{count}$ และ $\text{idf}=\log_{10}\dfrac{N}{\text{df}}$ แล้วอธิบายว่าทำไม "ที่" จึงได้ค่าเป็นศูนย์

| word | $d_1$ | $d_2$ | $d_3$ |
|:---:|:---:|:---:|:---:|
| เป็ด | 3 | 2 | 0 |
| ที่ | 10 | 8 | 9 |
| รถ | 0 | 0 | 5 |

$\mathbf{Sol}^{n}$

หา df ของแต่ละคำ (จำนวนเอกสารที่มีคำนั้น) แล้วคำนวณ idf, tf ในเอกสารที่ถาม และคูณกัน

$$
\begin{aligned}
\text{เป็ด: } \text{df}=2 &\Rightarrow \text{idf}=\log_{10}\tfrac{3}{2}=0.1761 \\
\text{ที่: } \text{df}=3 &\Rightarrow \text{idf}=\log_{10}\tfrac{3}{3}=0 \\
\text{รถ: } \text{df}=1 &\Rightarrow \text{idf}=\log_{10}3=0.4771 \\[4pt]
\text{tf-idf}(\text{เป็ด},d_1) &= (1+\log_{10}3)\times0.1761 = 1.4771\times0.1761 = 0.260 \\
\text{tf-idf}(\text{ที่},d_1) &= (1+\log_{10}10)\times0 = 2\times0 = 0 \\
\text{tf-idf}(\text{รถ},d_3) &= (1+\log_{10}5)\times0.4771 = 1.699\times0.4771 = 0.811
\end{aligned}
$$

"ที่" ปรากฏในทุกเอกสาร ($\text{df}=N$) จึงได้ $\text{idf}=\log_{10}1=0$ ไม่ว่าจะพบกี่ครั้ง TF-IDF ก็เป็น $0$ ส่วน "รถ" พบเฉพาะ $d_3$ ($\text{df}=1$) จึงได้ idf สูงสุด

$\mathbf{Ans}\quad \text{tf-idf}(\text{เป็ด},d_1)=\mathbf{0.260},\ \ \text{tf-idf}(\text{ที่},d_1)=\mathbf{0},\ \ \text{tf-idf}(\text{รถ},d_3)=\mathbf{0.811}$

หมายเหตุ ตัวอย่างตัวเลขในสไลด์ใช้ $\text{tf}=\log_{10}(\text{count}+1)$ ได้ $0.106,\ 0,\ 0.371$ ซึ่งไม่ตรงกับสูตรที่สไลด์เขียนไว้ ถ้าข้อสอบกำหนดสูตรมาให้ ให้ใช้ตามที่กำหนด

### ข้อ 5  ประโยค `... lemon, a tablespoon of apricot jam, a pinch ...` กำหนด target word คือ apricot หน้าต่าง $L=\pm2$ และ negative sampling $k=2$ จงระบุคู่ positive ทั้งหมดและบอกจำนวนคู่ negative

$\mathbf{Sol}^{n}$

คำบริบทคือคำที่อยู่ในหน้าต่าง $\pm L$ ของ target แต่ละคำบริบทให้ positive 1 คู่ และแต่ละ positive ให้ negative $k$ คู่ (สุ่มคำอื่นจากคลังคำ)

คำบริบทของ apricot ในหน้าต่าง $\pm2$ คือ tablespoon, of, jam, a รวม 4 คำ

| positive | $w$ | $c_{pos}$ |
|:---:|:---:|:---:|
| 1 | apricot | tablespoon |
| 2 | apricot | of |
| 3 | apricot | jam |
| 4 | apricot | a |

$$
\begin{aligned}

### ข้อ 6  จงหา $P(+\mid w,c)=\sigma(c\cdot w)$ เมื่อ $c\cdot w=0$ และ $c\cdot w=2$ (ตัวเลขที่ผมกำหนดเอง)

$\mathbf{Sol}^{n}$

แทนค่าในฟังก์ชัน sigmoid $\sigma(x)=\dfrac{1}{1+e^{-x}}$

$$
\begin{aligned}
\sigma(0) &= \frac{1}{1+e^{0}} = \frac{1}{2} = 0.5 \\
\sigma(2) &= \frac{1}{1+e^{-2}} = \frac{1}{1+0.1353} = 0.8808
\end{aligned}
$$

$\mathbf{Ans}\quad c\cdot w=0\Rightarrow P=\mathbf{0.5}$ (ไม่แน่ใจ) และ $c\cdot w=2\Rightarrow P=\mathbf{0.881}$ (น่าจะอยู่ใกล้กัน) ยิ่ง dot product สูง ยิ่งน่าจะเป็นคู่จริง

### ข้อ 7  กำหนด target $w$ มี positive $c_{pos}$ และ negative 2 ตัว $c_{neg_1},c_{neg_2}$ โดย $c_{pos}\cdot w=2$, $c_{neg_1}\cdot w=-1$ และ $c_{neg_2}\cdot w=1$ (ตัวเลขที่ผมกำหนดเอง) จงหา loss $L=-\left[\log\sigma(c_{pos}\cdot w)+\sum_i\log\sigma(-c_{neg_i}\cdot w)\right]$ (ใช้ log ฐาน $e$)

$\mathbf{Sol}^{n}$

แทนค่าแต่ละพจน์ใน loss โดยพจน์ negative ใช้ $\sigma(-c_{neg_i}\cdot w)$

$$
\begin{aligned}
\log\sigma(c_{pos}\cdot w) &= \log\sigma(2) = \ln 0.8808 = -0.1269 \\
\log\sigma(-c_{neg_1}\cdot w) &= \log\sigma(1) = \ln 0.7311 = -0.3133 \\
\log\sigma(-c_{neg_2}\cdot w) &= \log\sigma(-1) = \ln 0.2689 = -1.3133 \\
L &= -\left(-0.1269-0.3133-1.3133\right) = 1.7535
\end{aligned}
$$

$\mathbf{Ans}\quad L\approx\mathbf{1.7535}$ (พจน์ของ $c_{neg_2}$ ทำให้ loss สูง เพราะ $c_{neg_2}\cdot w=1$ แปลว่าโมเดลคิดว่าคำสุ่มนี้น่าจะอยู่ใกล้ target ซึ่งผิด)

### ข้อ 8  กำหนดเวกเตอร์ 2 มิติสมมติ (ผมกำหนดเอง ไม่ใช่ embedding จริง) $\text{king}=[0.9,0.8]$, $\text{man}=[0.5,0.1]$, $\text{woman}=[0.5,0.9]$, $\text{queen}=[0.9,1.6]$, $\text{prince}=[0.9,0.7]$ จงหา $b^*$ ในโจทย์ man : king :: woman : $b^*$ โดยเลือกจากคำ queen, prince, woman, man ด้วยวิธี parallelogram และระยะ Euclidean

$\mathbf{Sol}^{n}$

ใช้ $\hat{b}^*=\arg\min_x\,\text{distance}(x,\ b-a+a^*)$ โดย $a=\text{man}$, $b=\text{king}$ และ $a^*=\text{woman}$ คำนวณเวกเตอร์เป้าหมายก่อน แล้วหาคำที่ใกล้ที่สุด

$$
\begin{aligned}
b-a+a^* &= \text{king}-\text{man}+\text{woman} = [0.9-0.5+0.5,\ 0.8-0.1+0.9] = [0.9,\ 1.6] \\
d(\text{queen}) &= \sqrt{(0.9-0.9)^2+(1.6-1.6)^2} = 0 \\
d(\text{woman}) &= \sqrt{(0.9-0.5)^2+(1.6-0.9)^2} = 0.806 \\
d(\text{prince}) &= \sqrt{(0.9-0.9)^2+(1.6-0.7)^2} = 0.9 \\
d(\text{man}) &= \sqrt{(0.9-0.5)^2+(1.6-0.1)^2} = 1.552
\end{aligned}
$$

$\mathbf{Ans}\quad$ คำที่ใกล้ที่สุดคือ queen (ระยะ $0$) ดังนั้น man : king :: woman : $\mathbf{queen}$
